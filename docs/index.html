Teaching sequence

From decision to discussion

The project is designed for ordinary teaching settings. Students participate from their own devices, while the instructor uses live participant views and oTree reports to move from class choices to theory-driven interpretation.

1

Introduce

Rules, incentives, timing, and expectations are made explicit.

2

Participate

Students submit decisions through the web interface.

3

Display

Aggregate results are shown as tables, graphs, and reports.

4

Interpret

The class compares observed behavior with benchmark predictions.

Apps in EconExp

Current experiment modules

The repository contains four self-contained oTree apps covering strategic reasoning, social dilemmas, market price discovery, and decisions under risk. All modules support Italian and English interfaces and optional AI-generated feedback.

BEAUTY_CONTEST

Beauty Contest

A one-round guessing game based on Nagel (1995). Participants choose an integer from 0 to 100; the target is two thirds of the average guess, and the closest guess wins or splits a 100-point jackpot.

Concepts
Iterated reasoning, equilibrium, beliefs
Output
Guess distribution, target, participant AI feedback, aggregate admin report
Sessions
beauty_contest_eng, beauty_contest_ita
Source folder

PGG

Public Goods Game

A repeated public goods environment with groups of three, three rounds, an endowment of 100 points, and a multiplier of 2. Includes an interactive payoff calculator and round-by-round group feedback.

Concepts
Cooperation, free riding, group outcomes
Output
Round history, group averages, payoff ranking, instructor AI commentary
Sessions
public_goods_eng, public_goods_ita
Source folder

Market

Double Auction Market

A live continuous double auction where the instructor opens and closes trading rounds while students trade single units as buyers or sellers with private induced values and costs.

Concepts
Price discovery, competitive equilibrium, allocative efficiency
Output
Supply/demand schedules, live order book, price path, surplus & AI commentary
Sessions
market_eng, market_ita
Source folder

RISK_PREFS

Three Risk Tasks

Within-subject risk preference elicitation combining the Holt–Laury Multiple Price List, the Bomb Risk Elicitation Task (BRET), and the Gneezy–Potters investment task in randomized order after a short probability tutorial, plus the SOEP general risk question.

Concepts
Risk aversion, CRRA calibration, elicitation-method stability
Output
Cross-task CRRA estimates, consistency profile, participant & class AI feedback
Sessions
Risk_Prefs_Random_Order, Risk_Prefs_Random_Order_ITA
Source folder

Recent development

AI-mediated feedback for debriefing

Each module supports optional AI-generated commentary tailored either to individual students (on their results screen in BEAUTY_CONTEST and RISK_PREFS) or to the instructor (in the aggregate admin report for PGG, Market, and RISK_PREFS).

How it works

  • The app builds a structured JSON payload from observed choices, payoffs, summary statistics, and language settings.
  • Prompts enforce plain-language explanations grounded strictly in the observed numbers, avoiding speculative claims about motives.
  • Responses are cached by a hash of the session/player data so page reloads do not trigger duplicate API calls.
  • If the AI service is disabled or unavailable, the experiment runs normally without external calls.

Use the project

Run locally or deploy separately

This website is static and can be hosted by GitHub Pages. The oTree experiments themselves require a Python server and are not executed by GitHub Pages. 

pip install -r requirements.txt
otree devserver

Set OPENAI_API_KEY in your environment if you want to enable the optional AI feedback and admin-report commentary.
