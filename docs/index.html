Teaching sequence

From decision to discussion

The project is designed for ordinary teaching settings. Students participate from their own devices, while the instructor uses oTree reports to move from class choices to theory-driven interpretation.

1

Introduce

Rules, incentives, timing, and expectations are made explicit.

2

Participate

Students submit decisions through the web interface.

3

Display

Aggregate results are shown as tables, graphs, and reports.

4

Interpret

The class compares observed behavior with benchmark predictions.

Apps in EconExp

Current experiment modules

The repository currently contains two oTree apps for strategic interaction and cooperation. Both include participant pages, payoff logic, admin reports, and optional instructor-facing AI commentary.

BEAUTY_CONTEST

Beauty Contest

A one-round guessing game based on Nagel (1995). Participants choose an integer from 0 to 100; the target is two thirds of the average guess, and the closest guess wins or splits a jackpot.

Concepts
Iterated reasoning, equilibrium, beliefs
Output
Guess distribution, average, target, winners

PGG

Public Goods Game

A repeated public goods environment with groups of three, three rounds, an endowment of 100 points, and a multiplier of 2. Students choose contributions to a common project and see how group choices affect payoffs.

Concepts
Cooperation, free riding, group outcomes
Output
Round history, group averages, payoff ranking
Sessions
public_goods_ita, public_goods_eng

Recent development

AI-mediated feedback for debriefing

Selected apps can generate concise instructor-facing commentary from the aggregate data in the oTree admin report. The feature is optional and requires the OpenAI Python package plus an API key.

How it works

  • The app builds a structured payload from choices, payoffs, group statistics, and language settings.
  • The model is asked to produce a short HTML comment for classroom discussion.
  • Prompts require observed aggregate patterns and avoid unsupported claims about individual motives.
  • If the AI service is unavailable, the experiment still runs and the report shows a fallback message.

Use the project

Run locally or deploy separately

This website is static and can be hosted by GitHub Pages. The oTree experiments themselves require a Python server and are not executed by GitHub Pages. 

pip install otree
otree devserver

Install openai and set OPENAI_API_KEY if you want AI commentary in the admin reports.
